IRIS (Intelligent Real-time Image Sonification)

IRIS is an advanced Android-based assistive technology designed to provide real-time 
navigation and environmental awareness for visually impaired individuals. By leveraging 
computer vision and spatial audio, IRIS transforms visual data into actionable audio guidance.


Android (Kotlin)
YOLOv11, COCO dataset
TensorFlow Lite, Android CameraX API, Google Text-to-Speech
